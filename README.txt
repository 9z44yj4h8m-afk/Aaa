ALMOGHANI LIVE — الموقع الرسمي للمشغل العربي
===========================================

رابط الموقع:
https://9z44yj4h8m-afk.github.io/Z/

ملفات الموقع:
- index.html: الواجهة الأساسية ومشغل القنوات ولوحة الإدارة المحلية.
- channels-arabic.m3u: قائمة القنوات العربية المستخدمة في الموقع (75 مصدر بث عند آخر تحديث).
- .github/backups/index_before_horizontal.html: النسخة الاحتياطية القديمة، ليست صفحة بث منشورة للزوار.
- .github/workflows/build-apk.yml: إعداد بناء APK لتطبيق Android ونشره عبر GitHub Releases.

الأمان والخصوصية:
- يعرض الموقع القنوات العربية فقط.
- تظهر روابط البث داخل المشغل، وعُطّل فتح مصدر بث خارجي مباشرة من المشغل.
- لا يطلب الموقع بيانات مالية أو بيانات تسجيل الدخول لحسابات خارجية.
- رمز لوحة الإدارة محلي على المتصفح وليس نظام مصادقة لخادم.
- تعديلات اللوحة المحلية لا تُنشر لجميع المستخدمين إلا عند نشر صفحة أو بيانات جديدة.
- روابط البث لطرف ثالث، وتوفرها أو سلامتها أو ترخيصها خارج تحكمنا؛ يجب مراجعتها قبل إضافتها.
- لا يبدأ الموقع تنزيل برامج تلقائيًا؛ توجد وظيفة يطلب فيها المستخدم تصدير ملف M3U أو النسخة المعدّلة يدويًا.
